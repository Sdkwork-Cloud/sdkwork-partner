# 代理商层级体系与运营销售方案

> 对齐行业专业体系：云厂商伙伴计划（阿里云/华为云/腾讯云）、IT 渠道分销（总代—省代—区域分销）、加盟连锁的层级设计与激励模型。

## 1. 体系总览

### 1.1 七级金字塔

| 级别 | 名称 | 定位 | 加盟费 | 客户返佣池 | 加盟费提成池 |
| --- | --- | --- | --- | --- | --- |
| L1 | 普通代理 | 入门分销，跑量入口 | ¥5,999 | 10% | 8% |
| L2 | 银牌代理 | 成长伙伴，业绩进阶 | ¥9,999 | 12% | 10% |
| L3 | 金牌代理 | 核心渠道，主力销售 | ¥19,999 | 15% | 12% |
| L4 | 战略代理 | 区域经营，高价值客户 | ¥49,999 | 18% | 14% |
| L5 | 城市合伙人 | 城市独家经营 | ¥99,999 | 22% | 16% |
| L6 | 省级代理 | 省域运营与渠道管理 | ¥199,999 | 26% | 18% |
| L7 | 区域总代 | 大区总经销，深度共建 | ¥499,999 | 30% | 20% |

### 1.2 设计原则

- **全链条付费加盟**：每一级都缴纳加盟费（¥5,999 起），上级加盟费提成链条在任何级别加入时完整生效。
- **级差返佣（margin-safe）**：直接销售伙伴拿满本级返佣池，上级按「本级比例 − 链条已见最高比例」提取差额；**任意链条总返佣 ≤ 链条最高比例（30% 封顶）**，平台毛利按构造可控。
- **平滑递增**：返佣池 10% → 30%（差 2–4%），加盟费 5,999 → 499,999（约 2–2.5 倍），激励逐级递增、层级边界清晰。
- **区域维度完整**：城市 → 省级 → 大区（区域总代），与市场销售组织对齐。

## 2. 加盟与升级机制

### 2.1 加盟

- 按目标等级缴纳对应加盟费，由管理员登记收款并记入收益账本（支出），随即触发上级加盟费提成（级差制，`max_commission_depth` 默认 3 层）。
- 加盟费为一次性；续约/年费策略由运营按市场阶段决定（系统支持调整加盟费金额）。

### 2.2 升级（补差价晋升）

- 代理向上升级时**补缴两级加盟费差价**（如银牌 → 金牌补 ¥10,000），已缴部分不退回。
- 升级后按新等级比例计佣；升级当季业绩并入新等级考核。

### 2.3 考核与降级

- **季度业绩考核**：按季度累计客户消费额（绑定客户贡献）设定达标线，连续 2 季度未达标降一级；降到 L1 仍未达标则转为"普通代理观察期"。
- **降级处理**：降级后按新等级比例计佣，已达成未结算业绩不受影响；区域类权益（独家授权/区域保护）即时收回。
- 考核规则在管理端可配置（当前按比例/加盟费为硬参数，考核周期由运营制度执行）。

## 3. 返佣政策

### 3.1 收益来源与返佣基数（利润返佣）

- 客户使用量结算收益 + 客户充值收益（`revenue_sources` 可开关）。
- **利润返佣口径**：客户收益返佣的分配基数 = 客户收益 × 平台毛利率（`profit_margin_ratio`，默认 40%），**不是客户消费金额**。例如客户消费 ¥100、毛利率 40%，分配基数为 ¥40；30% 返佣池最多支付 ¥12（= 收入的 12%），平台保留 ¥28 毛利 + 上游成本后的净利。
- 加盟费返佣基数 = 加盟费全额（加盟费是平台收入，无上游成本）。
- 收益事件记录客户收益原始金额；结算单与分配明细记录实际使用的利润基数，口径可审计。
- 客户收益事件（已结算使用量、充值成功）→ 绑定归属 → 利润基数折算 → 级差分配 → 记账本。

### 3.2 结算

- 事件驱动结算：capture worker 采集 → 结算引擎逐级分配 → 写入收益账本；支持管理端手动触发与手工登记。
- 结算周期（默认即时/可配置）：L4 起可享受优先结算通道，L5 起快速结算通道。

### 3.3 提现

- 最低提现 ¥100（全局配置）；提现走申请 → 审核冻结 → 打款状态机。

## 5. 销售打法

### 5.1 各级销售定位与目标

- **L1/L2（跑量与成长）**：以个人/小微企业客户为主，主打"省钱+返佣"卖点；月度目标 1–3 万消费额。
- **L3/L4（核心与区域）**：以中型企业客户为主，顾问式销售+行业方案；月度目标 5–15 万消费额，商机线索转化率 ≥ 20%。
- **L5–L7（城市/省级/大区经营）**：以政企与行业客户为主，解决方案+联合营销打法；管理下级渠道，月度目标 30 万起，承担区域业绩与渠道发展指标。

### 5.2 标准打法（工具已内置）

1. 专属推广链接/二维码获客 → 客户绑定归属（防抢单：区域保护+报备制）。
2. 试用/体验 → 充值转化（充值收益返佣）。
3. 使用量增长 → 长期返佣（客户持续消费，代理持续收益）。
4. 下级招募 → 加盟费提成 + 下级业绩级差管理奖。

### 5.3 物料与话术（运营支持）

- 物料：品牌规范、宣传册、对比表、行业案例集、FAQ。
- 话术：价值主张（差价优惠+返佣收益）、竞对对比（省钱比例）、风险提示（合规红线）。

## 6. 运营节奏

| 周期 | 动作 |
| --- | --- |
| 周 | 商机线索分配、业绩周报 |
| 月 | 业绩榜单、月度回访、线索补给 |
| 季 | 季度考核（达标/降级）、季度激励发放 |
| 年 | 年度阶梯返利、认证年审、年度峰会、升级评审 |

## 7. 风险与合规

- **区域保护执行**：客户绑定归属 + 报备制度，防止跨区抢单；独家授权与区域保护即时生效/收回。
- **合规红线**：禁止多层级拉人头计酬（仅按客户消费与加盟费计酬）、禁止虚假交易刷单；收益全部入账本、可审计。
- **资金安全**：返佣发放经账户域账本（Credit），提现走冻结-打款状态机；全程审计留痕。

## 9. 权益 code 命名规范

权益列表的 `code` 字段是稳定的机器键，也是权益分类的约定来源：

| 分类 | 命名约定 | 示例 |
| --- | --- | --- |
| 返佣 | `commission_*` | `commission_pool` |
| 成长赋能 | `*_training` / `performance_*` / `certification` | `onboarding_training`、`advanced_training` |
| 运营支持 | `leads_*` / `*_support` / `*_sla` / `*_settlement` / `*_exclusive` / `*_protection` / 服务角色类 | `leads_monthly`、`account_manager`、`region_exclusive` |
| 市场激励 | `*_rebate` / `*_incentive` / `co_*` / `trade_show` | `annual_rebate`、`quarterly_incentive`、`co_branding` |
| 战略共建 | `joint_*` / `rnd_*` / `equity_*` / `summit_host` / `custom_sla` | `joint_solution`、`equity_plan` |

Admin 权益管理弹窗按该约定展示分类徽标；新建权益时应沿用对应分类的 code 前缀，保持运营视角的分类一致性。

# 多级合作伙伴（代理商）体系 PRD

## 1. 背景与目标

在 SDKWork 生态中建立多级合作伙伴（代理商）管理体系：

- 支持多级代理商层级，每级可配置独立的返佣比例与加盟费。
- 代理商缴纳加盟费加盟；上级代理商按配置比例逐级获得下级加盟费提成。
- 代理商发展客户，客户收益（使用量结算 + 充值）按配置比例逐级计提给代理商及其上级。
- 所有比例、金额均可配置；建立完善的代理商、客户、收益、提现、统计管理体系。

## 2. 核心规则

1. **等级体系**：等级动态可配，每级配置 `customer_revenue_ratio`（客户收益提成池比例）、`join_fee_commission_ratio`（加盟费提成池比例）、`join_fee`（加盟费金额）、`benefits`（等级权益清单，JSONB：code/name/value/sort）。安装即内置 7 级商业默认目录（普通代理 → 银牌 → 金牌 → 战略 → 城市合伙人 → 省级代理 → 区域总代，客户提成池 10%–30%、加盟费 ¥5,999–¥499,999），可在管理端调整；完整运营与销售方案见 `docs/product/ops/partner-tier-program.md`。
2. **加盟费**：代理商按其等级缴纳加盟费，缴纳记录由管理员登记，记入该代理商收益账本（支出）。
3. **加盟费提成（级差制）**：缴纳加盟费 F 时，链条中距离缴纳者最近的上级按「自身等级的提成池比例」提取，其上级按「本级比例与链条中已见最高比例之差」提取，逐级发放直至无上级或达到 `max_commission_depth`；**链条总提成恒等于链条中最高比例**，平台毛利按构造可控。
4. **客户收益提成（级差制 + 利润返佣）**：客户（IAM 用户）绑定代理商后，先按平台毛利率折算利润基数（`利润基数 = 客户收益 × profit_margin_ratio`，默认 40%），再按「客户所属代理(offset 0) 拿满本级提成池 → 直接上级(offset 1) 及更上级按本级比例与链条中已见最高比例之差提取」逐级分配，深度可配置；**链条总提成恒等于链条中最高比例（相对利润基数），折合收入不超过 最高比例 × 毛利率**。
5. **收益来源**：使用量结算（`commerce_usage_statement` 已结算）+ 充值（支付成功），`revenue_sources` 开关可配置。
6. **资金模型**：内部收益账本（钱包）+ 提现审批流（申请→审核冻结→打款标记）；支持管理员手工调账。
7. **账号绑定**：代理商必须绑定 IAM 用户；仅 ACTIVE 状态参与提成分配。
8. **幂等与审计**：收益事件唯一键 `(source_type, source_ref)`；所有写事务内完成并写审计日志。

## 3. 范围

一期（本期）：后端管理面（backend-api）完整管理体系 + 管理端前端 + 独立 SDK 家族。
二期（不在本期）：代理商自助端（app-api：自绑客户、查收益、自助提现）。

## 4. 验收标准

- 等级/比例/加盟费/权益全部可配置且留痕。
- 安装后启动即初始化 5 级默认等级目录（含权益与全局提成配置），种子幂等且不覆盖运营修改。
- 加盟费缴纳触发逐级提成，级差分配与配置一致（分精度，Σ = 级差池 = 链条最高比例 × 基数）。
- 客户收益事件触发逐级提成，级差分配与深度截断一致；任意链条 Σ ≤ 链条最高比例。
- 提现全流程状态机正确，账本余额守恒。
- 统计报表覆盖代理商、收益、提成、提现关键指标。
